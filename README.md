# Translator bot

Telegram-бот, который переводит твои сообщения на выбранный язык (по умолчанию — английский).
Он не отвечает на сообщение, а только переводит его: пишешь «Перезвонишь мне завтра?» — получаешь
«Can you call me back tomorrow?».

Переводит нейросеть: по умолчанию Gemini (у Google есть бесплатный тариф), можно переключить на Claude.
Бот передаёт смысл, тон и регистр, подбирает естественные для носителя формулировки вместо дословных
и не трогает ссылки, эмодзи, имена и переносы строк.

## Команды

- `/start` — справка и текущий язык
- `/lang` — выбрать язык кнопками
- `/lang суахили` — любой язык текстом

Язык запоминается для каждого пользователя в `data/settings.json`.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и возьми токен.
2. Возьми бесплатный ключ Gemini в [Google AI Studio](https://aistudio.google.com/apikey).
3. Узнай свой Telegram ID (например, у [@userinfobot](https://t.me/userinfobot)).
4. Настрой и запусти:

```bash
cp .env.example .env   # заполни TELEGRAM_BOT_TOKEN, GEMINI_API_KEY, ALLOWED_USER_IDS
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

`ALLOWED_USER_IDS` лучше заполнить: иначе бот будет переводить для любого, кто его найдёт,
и чужие сообщения съедят твой бесплатный лимит.

## Бесплатный тариф Gemini

- У бесплатного тарифа есть лимиты на запросы в минуту и в день. Когда лимит кончается,
  бот так и пишет; дневной лимит сбрасывается в полночь по тихоокеанскому времени.
  Актуальные лимиты своего проекта смотри в AI Studio.
- Google может использовать тексты с бесплатного тарифа для улучшения своих продуктов.
  Не переводи через него то, что не готов показать постороннему.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TRANSLATOR` | `gemini` | Движок: `gemini` или `claude` |
| `GEMINI_MODEL` | `gemini-flash-latest` | Модель Gemini (по умолчанию — свежая Flash) |
| `CLAUDE_MODEL` | `claude-opus-5-5` | Модель Claude, если `TRANSLATOR=claude` (нужен `ANTHROPIC_API_KEY`) |
| `CLAUDE_EFFORT` | `medium` | `low` — быстрее и дешевле, `high` — тщательнее |
| `SETTINGS_PATH` | `data/settings.json` | Где хранить выбранные языки |
