# Translator bot

Telegram-бот, который переводит твои сообщения на выбранный язык (по умолчанию — английский).
Он не отвечает на сообщение, а только переводит его: пишешь «Перезвонишь мне завтра?» — получаешь
«Can you call me back tomorrow?».

Перевод делает Claude (`claude-opus-5-5`). Бот передаёт смысл, тон и регистр, подбирает естественные
для носителя формулировки вместо дословных и не трогает ссылки, эмодзи, имена и переносы строк.

## Команды

- `/start` — справка и текущий язык
- `/lang` — выбрать язык кнопками
- `/lang суахили` — любой язык текстом

Язык запоминается для каждого пользователя в `data/settings.json`.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и возьми токен.
2. Возьми API-ключ на https://platform.claude.com.
3. Узнай свой Telegram ID (например, у [@userinfobot](https://t.me/userinfobot)).
4. Настрой и запусти:

```bash
cp .env.example .env   # заполни TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY, ALLOWED_USER_IDS
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

`ALLOWED_USER_IDS` лучше заполнить: без него бот будет переводить для любого, кто его найдёт,
а запросы оплачиваются с твоего ключа.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `CLAUDE_MODEL` | `claude-opus-5-5` | Модель для перевода |
| `CLAUDE_EFFORT` | `medium` | `low` — быстрее и дешевле, `high` — тщательнее |
| `SETTINGS_PATH` | `data/settings.json` | Где хранить выбранные языки |

Если модель откажется переводить сообщение по соображениям безопасности, запрос автоматически
повторяется на резервной модели (`fallbacks: "default"`).
